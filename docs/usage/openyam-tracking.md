# OpenYAM tracking compensation

The bounded holding controller is available on both OpenYAM adapters when `tracking_comp=True`. The J3 moving model is available only through `execute_j3_trajectory` or explicit `begin_j3_motion` / `end_j3_motion` calls. Its measured range is 0.16–0.40 rad at no more than 0.04 rad/s and 0.1 rad/s². The model is an empirical correction in reported protocol torque units. It is not an identified physical gravity or friction model.

The controller requires the `fix/openyam-anvil-parity` build of `can-motor-control` at commit `20572f3a41dd98d692da44556de0a0d10c2c8d9d`. Install it into this checkout with `scripts/openyam/install_anvil_parity.sh`; pass a local path to that exact source commit to build offline. The regular `uv.lock` resolves the published 0.0.8 package. Use `uv run --no-sync` when testing this experimental integration so uv does not replace the installed 0.1.0 parity build. The adapter rejects tracking activation unless `openyam_anvil_parity=True` and the installed package reports at least 0.1.0.

Set `tracking_comp=True, openyam_anvil_parity=True` in `openyam_hardware` or `dual_openyam_hardware`. The parity adapter adjusts J1–J3 desired wire velocity by 8/10 and rescales decoded velocity by 10/8, matching the motor registers observed in the calibration session. The position setpoint is unchanged. Default runtime settings leave this correction inactive.

To run a J3 profile, use `ArmOnlyDualOpenYamDamiaoAdapter` (registry name `dual_openyam_arms_only_damiao`) so activation does not calibrate or move grippers. Activate the adapter, reach and hold a start pose within 0.3° of its commanded J3 target, and pass an arm command vector containing all joints. The trajectory method requires a `check_path(start, end)` callback to verify joint limits, table clearance and collisions, and an `observe(states)` callback for deployment-specific feedback checks and cancellation. It checks enabled/fault state, temperature and tracking error internally. The method commands a two-second cosine acceleration ramp, a constant-speed segment, and a two-second deceleration ramp at 100 Hz, while transferring the delivered J3 torque between motion and holding policies. The caller must handle a guarded return and deactivation on interruption; the method raises rather than attempting a return from an unknown pose.

The calibration source and measurements are under `/home/dimos/calibration/openyam_camera_calibration_20261027_i3h7w6ox/gravity_friction_identification/feedforward_validation5`. The final run reduced J3 peak motion error at 0.04 rad/s from 1.38° to 0.37° left and 1.59° to 0.42° right. A slower right-arm stop missed the ±0.2° within two seconds target. These results do not validate other joints, loads, contact, or the full workspace. The 3° near-zero diagnostic run used baseline mode and did not test this moving model.
