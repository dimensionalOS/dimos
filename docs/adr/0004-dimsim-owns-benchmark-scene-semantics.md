# DimSim owns benchmark scene semantics

DimSim will own the authoritative semantic facts needed to generate benchmark tasks, including semantic classes, canonical object orientation, rooms, and scene relationships, rather than letting each benchmark maintain a parallel annotation layer. DimSim will expose these facts through a private simulator oracle surface with provenance for authored and policy-derived values; evaluated agents will continue to receive only normal runtime observations and task language. The benchmark generator will consume one typed, read-only `SceneOracleView` from a coherently reset scene, normally in memory, and retain only its content digest and provenance in the generated corpus. This keeps one scene truth source, makes the metadata reusable beyond one benchmark, and prevents benchmark annotations from drifting away from simulator assets and state.
