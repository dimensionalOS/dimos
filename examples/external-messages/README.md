# External message registration example

`DeviceReading.msg` defines an external message that reuses the installed DimOS
Header. `demo_reading.py` checks registration, a CDR roundtrip and type identity.

See the [installation and run instructions](../../docs/development/messages-external-project.md#install-and-run)
for complete commands using the built-in example environment, expected output
and how to reinstall after changing a definition.
