# DIOS provenance

dimup ports installation responsibilities from dimensionalOS/dios at commit
f19eda9506352166404507f1a564c493ff154a26 into the DimOS repository.
The Python implementation retains tool discovery, explicit setup stages, and
environment preparation. It excludes the frontend, app manager, services,
self-updater, and robot-host deployment. There is no second installer repository
or vendored Rust application to maintain.
